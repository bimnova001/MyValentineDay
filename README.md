# 💖 Valentine’s Day Web

A simple interactive Valentine website built with HTML, CSS, and JavaScript.

## ✨ Features

- 💕 Liquid Glass style card
- 💖 Floating heart animation
- ❤️ Yes / 💔 No interaction
- 🌸 Romantic pink theme
- 🌫 Sad mode (grey theme + background change + 💔)
